Which feature enhancements do you want?

Select any that are in scope — these are additions on top of the UX fixes. Multi-select.

DASH

Dashboard — Quick Action Bar

One-click shortcuts at the top: "Create PO", "Upload Doc", "Review Pending (N)". Saves 2-3 clicks for the most common daily actions.

DASH

Dashboard — Stats with Trends

Show delta vs yesterday on each stat card (e.g. "↑3 pending reviews"). Helps operators spot if backlog is growing.

DASH

Dashboard — Document Status Donut

Visual breakdown of all documents by status (Verified / Pending / Failed / Extracting). Instant pipeline health at a glance.

PO LIST

PO List — Saved Filter Presets

Save frequently used filter combos (e.g. "My pending Redington POs") and recall them with one click. Useful when the same filters are applied daily.

CUST

Customers — Customer Detail Page

Dedicated page showing: PO count, total order value, recent POs list, contact info, chain health summary. Currently all this is hidden.

DOCS

Documents — Bulk Re-extract

Select multiple failed/pending documents and trigger re-extraction in one click. Avoids opening each PO individually.

PO DTL

PO Detail — Chain Complete State

When chain hits 100%, show a green "All documents complete" banner with a link to the Profile view. Currently looks identical at 50% and 100%.

PROFILE

PO Profile — Sticky Section Navigation

Fixed left sidebar with jump-links to each section (Overview, Discrepancies, Items, Vendors, Documents, Timeline). Essential — the page has 8 sections and no way to navigate.

PROFILE

PO Profile — Print / PDF Export

Clean print layout of the full profile (for physical records or email attachments). Different from the Excel export — this is the human-readable summary.

SEARCH

Search — Recent Searches + URL State

Persist tab and filter state in the URL (shareable links). Show last 5 searches as quick-picks. Small but makes search feel polished.

ADMIN

Admin/System — Live Activity Feed

Rolling log of recent events: "INV-001 verified by admin", "PO-1045 extraction failed", "Re-extraction queued". Replaces the silent "currently active" table.

GLOBAL

Global — Toast Notifications

Success/error toasts for all actions (verify, reject, upload, create PO). Currently most actions are silent. Already exists on POProfile — extend to all pages.

GLOBAL

Global — Breadcrumbs

Show hierarchy trail on detail pages: Dashboard → Purchase Orders → PO-1045 → Profile. Helps users know where they are and navigate back.

Note: Global Toasts + Customer Detail Page + PO Profile Sticky Nav are the three I'd consider essential. Everything else is a genuine enhancement.
