⚡ Operator Efficiency

REVIEW

Keyboard shortcuts in Review Modal

V = Verify, R = Reject, Esc = Close. Operators doing 30–50 reviews a day will feel this immediately. No mouse needed for the most repetitive action in the whole app.

High daily impact Low effort
PO DTL

Multi-file upload to a PO

Upload several documents at once to the same PO — drag a folder or select multiple files. Currently you upload one at a time per slot. For a new PO with 6 doc types, that's 6 separate upload flows.

Saves significant time
DOCS

Bulk re-extract failed documents

Select multiple failed docs in the Documents page and re-queue them all at once. Right now you open each PO one by one to hit Re-extract.

Medium impact

⏰ Alerting & Visibility

DASH

Aging / SLA alerts on Dashboard

Flag documents that have been PENDING_REVIEW for more than N days with a red badge. In logistics, a document sitting unreviewed for 5 days can hold up a delivery. Makes the problem visible before it becomes urgent.

Prevents operational issues
GLOBAL

In-app notification bell

Persistent bell icon in the header showing unread events: "Extraction complete for PO-1045", "3 docs need review", "Re-extraction failed". Toasts disappear — this stays. Useful when multiple tabs are open.

Medium effort

🔍 Search & Navigation

SEARCH

Autocomplete dropdown in inline search

The top-bar search already exists (InlineSearch). Add a dropdown that shows matching PO numbers, customers, and ref numbers as you type — without navigating to the Search page. Like a command palette.

High discoverability
GLOBAL

Breadcrumbs on detail pages

Show the path: Purchase Orders → PO-1045 → Profile. Currently PO Detail and PO Profile have back-links but no hierarchy context. New users constantly get lost.

Low effort
